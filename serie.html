L'Auteur

Kael Solano

Auteur de fiction initiatique

Ces romans ne sont pas une fiction sur les Andes — ils sont une traversée de leur sagesse. À travers la série Le Chemin de l'Être, Kael Solano met en fiction pour la première fois les sept codes de la tradition Q'ero, tels qu'ils peuvent être vécus, pas seulement compris.

Chaque tome est un code. Chaque code est une clé. Ce n'est pas un voyage vers soi — c'est un retour.
